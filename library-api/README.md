# Library API (OpenAPI spec)

Этот проект содержит пример спецификации OpenAPI 3.0.3 для REST API **Library API**, предназначенного для управления библиотечным каталогом книг и авторов.

Спецификация оформлена как выполненное тестовое задание и демонстрация навыков описания REST API в формате OpenAPI.

## Содержимое

- `openapi.yaml` — спецификация OpenAPI 3.0.3 для Library API:
  - Описание эндпоинтов для управления книгами (`/books`, `/books/{id}`).
  - Описание эндпоинтов для управления авторами (`/authors`, `/authors/{id}`).
  - Схемы запросов и ответов: `CreateBookRequest`, `Book`, `CreateAuthorRequest`, `Author`.
  - Схемы пагинированных списков: `BooksList`, `AuthorsList`.
  - Коды ответов и описания ошибок для каждого эндпоинта.

## Что делает API

Library API предоставляет два набора операций:

- **Книги**
  - `POST /books` — добавить книгу в БД.
  - `GET /books` — получить список книг с фильтрацией по жанру и пагинацией.
  - `GET /books/{id}` — получить информацию о книге по ID.
  - `PUT /books/{id}` — обновить информацию о книге.
  - `DELETE /books/{id}` — удалить книгу.

- **Авторы**
  - `POST /authors` — добавить автора в БД.
  - `GET /authors` — получить список авторов с пагинацией.
  - `GET /authors/{id}` — получить информацию об авторе по ID.
  - `PUT /authors/{id}` — обновить информацию об авторе.
  - `DELETE /authors/{id}` — удалить автора.

## Как использовать спецификацию

Вы можете:

- Импортировать `openapi.yaml` в [Swagger UI](https://swagger.io/tools/swagger-ui/) или [Redoc](https://redocly.com/redoc/) для интерактивного просмотра документации.
- Открыть файл в [Swagger Editor](https://editor.swagger.io/) для валидации и просмотра.
- Использовать спецификацию как основу для генерации клиентского кода или серверных заглушек.
