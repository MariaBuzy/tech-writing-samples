# tech-writing-samples

Портфолио‑репозиторий с примерами технической документации и формальных описаний API в разных форматах (OpenRPC, WSDL, gRPC).

## Цель репозитория

Цель этого репозитория — показать:

- умение описывать JSON-RPC API в формате OpenRPC (структура методов, параметры, результаты, обработка ошибок);
- понимание основных элементов SOAP/WSDL 1.1 (types, message, portType, binding, service) и умение оформить спецификацию веб-сервиса;
- навыки проектирования и описания gRPC API в формате proto3 (messages, service, CRUD-операции, пагинация);
- внимательность к структуре, примерам и консистентности именования;
- умение писать лаконичную и однозначную техническую документацию (README и встроенные описания).

## Структура репозитория

- `secure-storage-api/`  
  Спецификация JSON-RPC API в формате **OpenRPC** для сервиса безопасного хранения пользовательских данных.  
  Включает:
  - `openrpc.json` — OpenRPC-документ с описанием метода `manageSecretData`, примерами вызовов и кодами ошибок;
  - `README.md` — краткое текстовое описание API и его назначения.

- `task-management-api/`  
  Спецификация SOAP веб-сервиса управления задачами в формате **WSDL 1.1**.  
  Включает:
  - `taskmanagement.wsdl` — WSDL-документ с типами, сообщениями, портом, привязкой и сервисом;
  - `README.md` — описание возможностей сервиса и структуры WSDL.

- `online-store-grpc-api/`  
  Спецификация gRPC-сервиса онлайн‑магазина в формате **proto3**.  
  Включает:
  - `gRPC.proto` — определения сообщений и сервиса `OnlineStore` (товары, категории, привязка, списки, пагинация);
  - `README.md` — описание функциональности сервиса и структуры `.proto` файла.
