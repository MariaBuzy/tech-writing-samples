# tech-writing-samples
Репозиторий содержит учебные примеры технической документации для API, выполненные в рамках курса «Проектирование архитектуры и интеграций сервисов» (Stepik, 2026).

|product-service.yaml|OpenAPI 3.0|Спецификация REST API для управления продуктами и категориями интернет-магазина|
|-------------|-------------|-------------|
|product-service.wsdl|WSDL 1.1|SOAP-описание сервиса управления продуктами|
|Файл|Формат|Описание|
|product-service.proto|Protobuf/gRPC|gRPC-спецификация сервиса управления продуктами и категориями|

Описание предметной области
Документация описывает API для управления каталогом интернет-магазина.
**Сущности:**
- **Продукт** - ID, название, описание, цена, количество на складе, список категорий
- **Категория** — ID, название, список продуктов
**Операции**
- Создание, редактирование и удаление продуктов и категорий
-Привязка и отвязка продукта от категории
- Получение списка продуктов с фильтрацией по цене и пагинацией
- Получение детальной информации по ID
**Инструменты**
**Swagger Editor** — просмотр и валидация OpenAPI-спецификации
**SoapUI** — тестирование WSDL
**VS Code + расширение Protobuf** — редактирование .proto файлов
