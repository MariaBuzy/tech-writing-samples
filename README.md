# Secure Storage API (OpenRPC spec)

Файл secure-storage-api содержит пример спецификации OpenRPC для условного JSON-RPC 2.0 API **Secure Storage API**, предназначенного для безопасного хранения и управления секретными пользовательскими данными.

Спецификация оформлена как демонстрация навыков в разработке технической документации и работы с форматом OpenRPC.

## Содержимое

- `openrpc.json` — спецификация OpenRPC 1.2.6 для метода `manageSecretData`.
  - Описание сервера и версионирования API.
  - Структура параметров и результата метода.
  - Справочник кодов ошибок.
  - Примеры успешных и ошибочных вызовов.

## Что делает API

Secure Storage API предоставляет один метод `manageSecretData`, который позволяет:

- добавлять новые записи с секретными данными пользователей (`action = add`);
- получать существующие записи по идентификатору (`action = get`);
- удалять записи при наличии достаточных прав (`action = delete`).

Доступ к операциям контролируется уровнем доступа (`user`, `admin`, `superAdmin`), а язык сообщений об ошибках и уведомлений задаётся через параметр `language` (например, `ru-RU` или `en-US`).

## Как использовать спецификацию

Вы можете:

- валидировать `openrpc.json` с помощью официальной JSON Schema для OpenRPC;
- импортировать файл в инструменты, поддерживающие OpenRPC (например, playground.open-rpc.org);
- использовать спецификацию как основу для генерации клиентского кода или документации.
