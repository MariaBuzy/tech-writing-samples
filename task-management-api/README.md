# Task Management SOAP API (WSDL spec)

Этот проект содержит пример WSDL-спецификации для SOAP веб-сервиса **Task Management Service**, который предоставляет операции для управления задачами (создание, получение, обновление и удаление).

Спецификация оформлена как демонстрация навыков технической документации и описания SOAP-сервисов на языке WSDL 1.1.

## Содержимое

- `taskmanagement.wsdl` — WSDL-описание сервиса Task Management Service.
  - Определение XML-схемы элемента `Task` (ID, заголовок, описание, статус).
  - Сообщения (messages) для запросов и ответов.
  - Интерфейс сервиса (`portType`) с операциями `CreateTask`, `GetTask`, `UpdateTask`, `DeleteTask`.
  - Привязка (`binding`) для SOAP 1.1 с документно-ориентированным стилем (`document/literal`).
  - Описание сервиса и конечной точки (`service` и `port`).

## Что делает сервис

Task Management Service предоставляет четыре операции:

- **CreateTask** — создание новой задачи на основе переданного объекта `Task`.
- **GetTask** — получение задачи по идентификатору `TaskID`.
- **UpdateTask** — обновление существующей задачи.
- **DeleteTask** — удаление задачи по идентификатору.

Для всех операций используется единый ответ с элементом `Task`, что упрощает структуру примера и делает его компактным.

## Как использовать WSDL

Вы можете:

- импортировать `taskmanagement.wsdl` в инструменты для работы с SOAP (например, SoapUI) и сгенерировать пример запросов;[web:69]

- адаптировать структуру под ваши учебные примеры SOAP-сервисов.
