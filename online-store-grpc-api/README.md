# Online Store gRPC API (proto3)

Этот проект содержит пример protobuf-схемы и gRPC-сервиса **OnlineStore**, предназначенного для управления товарами и категориями в условном онлайн-магазине.

Спецификация оформлена как демонстрация навыков работы с gRPC/proto3 и описания API на уровне контрактов.

## Содержимое

- `gRPC.proto` — схема в формате proto3 для пакета `onlinestore`:
  - описания сообщений `Product` и `Category`;
  - отдельные request/response-типов для операций добавления и редактирования;
  - сообщения для простейшей пагинации списка товаров и категорий;
  - сервис `OnlineStore` с набором RPC-методов.

## Функциональность сервиса

Сервис `OnlineStore` предоставляет следующие группы операций:

- **Работа с продуктами**
  - `AddProduct` — создание нового товара.
  - `EditProduct` — редактирование существующего товара.
  - `DeleteProduct` — удаление товара по идентификатору.
  - `GetProduct` — получение информации о товаре по ID.
  - `ListProducts` — получение списка товаров с пагинацией.

- **Работа с категориями**
  - `AddCategory` — создание новой категории.
  - `EditCategory` — редактирование категории.
  - `DeleteCategory` — удаление категории по идентификатору.
  - `GetCategory` — получение информации о категории по ID.
  - `ListCategories` — получение списка категорий с пагинацией.

- **Связь товаров и категорий**
  - `LinkProductToCategory` — привязка товара к категории.
  - `UnlinkProductFromCategory` — отвязка товара от категории.

Для типовых операций используется общий ответ `StatusResponse` с булевым полем `success`.

## Структура данных

- `Product` содержит:
  - `product_id`, `name`, `description`, `price`, `quantity`;
  - список идентификаторов категорий `category_ids`.

- `Category` содержит:
  - `category_id`, `name`;
  - список идентификаторов товаров `product_ids`.

- Для пагинации используются сообщения:
  - `ListProductsRequest` / `ListProductsResponse`;
  - `ListCategoriesRequest` / `ListCategoriesResponse`  
  с полями `page_size`, `page_number`, `next_page_number`.
